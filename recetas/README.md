# Recetas
Pendiente: incorporar menú y recetario fuente. No hay recetas técnicas cargadas ni aprobadas en este repositorio.

Cada ficha debe identificar:
- Código, producto, versión y documento fuente.
- Estado: preliminar, en validación o aprobada.
- Rendimiento, porción, ingredientes y cantidades documentadas.
- Equipo, procedimiento y controles documentados.
- Alérgenos verificados con etiquetas y subrecetas.
- Presentación y conservación documentadas.
- Responsable y fecha de aprobación, únicamente cuando exista evidencia.

No completar vacíos con supuestos. El menú comercial no sustituye una formulación técnica.
